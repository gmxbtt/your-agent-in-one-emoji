One emoji stands for this AI agent: 🪞, the mirror. A personal agent is its user's reflection — it watches what the user wants, acts as their stand-in while they sleep, and hands back work that looks like the user did it themselves. No robot, no smiley: the agent's whole job is to be you, when you are not there.

## Run it

```sh
python3 main.py
```

The program writes the single emoji to `/output/entry.txt` (and prints it). It is fully deterministic: the same glyph on every run.
